# SDK 升级回归测试清单

> 升级范围：`ali-oss` `6.13.2` → `6.23.0`（2025-05-14 发布）；`axios` `0.21.4` → `1.20.0`（2026-08 发布）
> 升级目的：ali-oss 获得依赖安全修复（移除 vm2 相关传递依赖、urllib/agentkeepalive 升级）与多年 bug 修复，可选支持 V4 签名；axios 清除 22 条历史安全通告（SSRF/prototype pollution 等，0.x 已无修复）

## 升级前须知的行为变化（重点）

| 变化 | 来源 | 对本项目影响 |
|---|---|---|
| `signatureUrl()` 从 6.19.0 起**默认开启对象名严格校验** | CHANGELOG 6.19.0 | 生成下载/二维码地址时，含空格/中文/特殊字符的文件名可能报错或需显式传 `strictObjectNameValidation: false` |
| `urllib` 等底层请求库升级 | 6.18.1 | 理论上行为不变，需回归上传/下载链路 |
| multipart 上传相关修复（progress 回调、header 透传等） | 6.16–6.21 | 需回归断点续传与进度显示 |
| 新增 V4 签名能力 | 6.20.0 | 本项目当前用默认 V1 签名，**不强制切换**；如未来 Bucket 开启仅 V4 策略需适配 |

## 二、手工功能回归
